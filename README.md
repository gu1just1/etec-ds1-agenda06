# Agenda 06 - Estruturas de Decisão (Desenvolvimento de Sistemas I)

Programa em Python desenvolvido para cálculo de desconto progressivo sobre compras online conforme critérios da Agenda 06.

## Regras de Negócio
- Compras abaixo de R$ 200,00: **5%** de desconto
- Compras de R$ 200,00 até R$ 299,99: **10%** de desconto
- Compras a partir de R$ 300,00: **15%** de desconto

## Execução
```bash
python GuilhermeJusti_Ag6_DS_I.py
